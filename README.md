# cosTapered

Bayesian change-of-support model with tapered exponential covariance for
raster covariates, observed-support polygons, and areal prediction polygons.

## Status

Under active development.

## Installation

```r
remotes::install_github("YOUR-GITHUB-USER/cosTapered", subdir = "cosTapered")
```

## Package Source

The R package source is in `cosTapered/`.
